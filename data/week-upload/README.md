# 週間スケジュール画像のアップロード先

公式X の週間スケジュール画像（JPG / PNG / WebP）をこのフォルダにアップロードして commit すると、GitHub Actions が画像を読み取って `data/week.json` を作り直します（数分）。

- ファイル名はそのままで構いません。いちばん新しく commit した画像が使われます。
- アップロードした画像は、それより古い X の投稿より優先されます。次の週の X 投稿が出れば、そちらに切り替わります。
- 読み取った結果は管理画面の「週間スケジュール」で確認・修正できます。
- 古い画像は消しても消さなくても構いません（8日より前の画像は読みません）。
